## Overview

FORGEWHEEL is a personal game development project focused on building a complete arcade racing experience while applying professional software engineering practices.

The project emphasizes:

* Modular and maintainable code architecture
* Vehicle physics using Unity's WheelCollider system
* AI-controlled opponent
* Race game mode(Build 1)
* Score Attack game mode(Build 2)
* Garage and vehicle selection systems
* Clean UI implementation
* Data-driven design using ScriptableObjects
* Preparation for future multiplayer using Netcode for GameObjects (NGO)

Rather than relying on tutorials alone, this project documents real development challenges, architectural decisions, and problem-solving throughout production.

## Features

### Vehicle System

* WheelCollider-based vehicle physics
* Adjustable suspension
* Front-wheel drive
* Rear-wheel drive
* Four-wheel drive
* Speedometer
* Lap timer
* Personal best tracking
* Rear-view mirror
* Vehicle camera system

### AI

* Waypoint-based transform target navigation
* Configurable racing paths
* Dynamic steering and acceleration
* Expandable architecture for future spline navigation

### Gameplay

* Race Mode(Build 1)
* Lap timing system
* Personal best saving
* Garage scene
* Vehicle selection
* Countdown system
* Finish line detection
* Score Attack Gamemode(Build 2)

### UI

* Responsive UI
* Speedometer
* Lap timer
* Best lap display
* Garage interface
* Resolution-independent Canvas scaling

### Architecture

* ScriptableObject-driven vehicle configuration
* Modular scripts
* Separated gameplay systems
* Scalable project structure
* Designed with future multiplayer integration in mind
